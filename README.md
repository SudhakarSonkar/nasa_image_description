# 🚀 NASA Astronomy Picture of the Day (APOD)

This project fetches and displays the **NASA Astronomy Picture of the Day** using the NASA Open API.  
It shows the **title, image, and explanation** inside a **Streamlit web app**.

---

## 🌍 Live Demo  
👉 [Check the app live here](https://sudhakarsonkar-nasa-image-description-nasa-images-root-rieocq.streamlit.app/)

---

## 📌 Features
- Fetches NASA’s **Astronomy Picture of the Day (APOD)**.
- Downloads and saves the image locally.
- Displays the **title, image, and explanation** in a Streamlit app.
